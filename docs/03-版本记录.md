# 版本记录

## V0.2（开发中 · 2026-09-20 ~ 09-21）

### 本次新增

- **语音输入（M8）**：开麦后持续聆听，说话自动转写并**填入输入框等待确认，永不自动发送**。PCM 采集手拼 16k WAV（不用 MediaRecorder），串行发送队列 + 60s 超时 + 尾部静音裁剪。实测硅基流动 SenseVoiceSmall 是少数允许浏览器直连的 ASR；连接失败内置网络自诊断提示。
- **看板风格改版（M9）**：AI 对话页整页深海军蓝，声场球固定顶部换霓虹皮肤（线框球+倾斜粒子轨道环+辉光），画布升级为无限画板（点阵网格 + 自由摆位 + 缩放平移 + Ctrl+滚轮）。

### M9.2（2026-09-22）· 对话区加长（沉浸模式）

- 坑：预览管线会把 HTML 做 DOM 往返序列化并写回源文件（注入 `data-page-node-id` / `__dm_*` style / body 运行时 class，SVG 自闭合标签被展开）→ 体积虚增 47KB。已从 HEAD 恢复并重打改动；`present_files` 之后务必核对文件大小与 `git diff --numstat`

- **B 版按反馈迭代为 B2**：打卡完成态酸绿 `#b6ff3d` → 琥珀金 `#ffc93d`（用户不喜欢绿色）；
  切角（`clip-path`）→ 圆角 10px（明显但克制，小卡 8px）；去掉裁剪后改用多层 `box-shadow`，
  辉光强度全面提升（背景光晕 alpha 近乎翻倍、卡片三层外发光 + 内发光、文字辉光加强）；
  角标同步改圆角取景框
- **B3（收敛版）**：辉光回调一档（所有 `box-shadow`/`text-shadow`/`drop-shadow` 的模糊半径 ×0.75×0.90、
  alpha ×0.70×0.84，背景光晕同步降），实测画面「光晕能量」12.96 → 10.52（-19%）；
  完成态琥珀金 `#ffc93d`（偏暖）→ **纯金 `#ffd700`**；圆角再收一档：卡片 10→8px、小卡 8→6px
- **B4（冷黄 + 再暗）**：完成态纯金 `#ffd700`（色相 51° 仍偏暖）→ **冷柠檬黄 `#f0ec3d`**（色相 59°，
  红分量低于纯金、绿分量抬升，视觉偏黄带冷感，不落进黄绿区）；辉光能量 10.35 → **9.04**
- **辉光构成分解实验（关键）**：删掉全部 51 处 shadow 重渲染，光晕能量 10.35→10.32 **几乎不变**，
  但亮部峰值 p95 66→51；删掉背景光晕+网格+扫描线则 10.35→8.39。
  → 结论：**大面积底噪亮度由背景层（radial-gradient 光晕 / 点阵网格 / CRT 扫描线）决定，
  shadow 只决定局部高光**。想让画面"暗下来"必须压背景层，压 shadow 无效（前两轮白调）。
  调参脚本：`.workbuddy/tune-mockup-b4.js`（背景光晕 ×0.65、网格与扫描线 ×0.65、shadow alpha ×0.72）
- **B5（去饱和 · 提格调）**：主色从 S100% 降到 ~85% 并往冷偏——青 `#00f0ff` → `#22d3ee`（色相 +7° 更冷）、
  品红 `#ff2ea6` → `#f0429e`、紫光晕 `#8b5cf6` → `#7c74d6`；亮边框 `--line-hi` .62→.40、
  顶部霓虹高光条 .95/.8→.5/.42、网格不透明度 .75→.58、卡内品红余晖 →.016（做减法，卡片透气）；
  底色再压暗（`#04040a`→`#030307`，卡片渐变三段同步降），文字 `#eaf8ff`→`#d9e5f2` 去刺眼。
  完成态 → **荧光黄带草绿 `#e6ff4a`**（色相 68°，绿分量略高于红，落在柠檬黄与草绿之间）。
  实测：光晕能量 9.04 → **7.60**（相对最初 12.96 累计 -41%），亮部彩度 chroma 72.9 → **59.8**（-18%），
  但亮部峰值 p95 仍保 60 —— 暗下来而高光不丢
- 度量补充：`png-luma.js` 增加 satBright / vivid% / chromaBright 三个「艳度」指标（只统计 luma>40 的像素，
  否则暗底会把饱和度平均拉飞，出现「A 版看着克制但指标更高」的反直觉结果）

- 点阵（斐波那契）球回归为**默认皮肤**，霓虹皮肤保留可一键切换（按钮持久化到 localStorage）
- 点阵球视觉增强：新增高对比配色 dark2（亮青-品红），光晕/核心/射线亮度全面上调，取景台底色压暗

## V0.1（2026-09-19）

把「记生活」升级成「能聊、能记、能看见」。AI 接入 + 工具调用 + 记忆 + 声场球 + 画布空间，五个里程碑一次成型。

### 本次新增

- **AI 接入（M1）**：OpenAI 兼容协议，Base URL / 模型名 / API Key 三件套通吃各家；多配置可存可切。密钥只存本机 localStorage，**不进导出的备份文件**（导出前有正则守卫兜底）。已实测 CORS：DeepSeek / 百炼 / 火山 / 智谱 / Moonshot / 硅基流动全部允许浏览器直连 → 纯前端直连，不需要后端代理。
- **AI 对话（M2）**：SSE 流式，逐字上屏；对话框形态（我在右、AI 在左，带头像与时间）。流式失败自动回退非流式再试一次。
- **工具调用（M3）**：AI 能真的改你的数据，但有三道保险——① 写操作先出**预览卡**（写明"从什么改成什么"）等人点确认；② 执行前全量快照入撤销栈（最近 5 次，可一键撤销）；③ 工具名归一化 + 参数校验。
- **记忆层（M4）**：`save_memory` 三道闸门——结构化 schema（缺字段整批拒收）、来源分级（`stated` 用户说的 / `inferred` 你推断的，**无 evidence 一律拒收**）、敏感黑名单（健康/财务/位置/密钥命中即拒，连确认卡都不弹）。冲突检测**并列保存不覆盖**。打分取 top-12 注入系统提示。
- **声场球（M5）**：从 3D_soundfield 移植的 Canvas 2D 手写 3D 投影球，零依赖。四态 `idle / listening / thinking / speaking`，三个维度同时区分（点阵层内外、光晕内收外扩、色相旋转）。语音活动检测：自适应底噪 1.2s + 双门限滞回 + hangover 500ms + 300~3000Hz 人声加权。麦克风只在点击时申请，**离开板块必收摊**（停 rAF + 停音轨 + 关 AudioContext）。
- **画布空间（M7）**：AI 通过 `render_canvas` 工具把结构化内容落到右侧画布——`explain` 结构化解释、`plan` 目标拆解、`flow` 流程/逻辑关系图（SVG 自动分层布局）。画布渲染不打断对话；`plan` 的「落到今日清单 / 存成长期目标」才走写操作确认卡。

### 界面调整

- 对话板块改为**左右双栏**：左对话，右「声场感应 + 画布空间 + 预留位」
- 声场球从 152px 条状升级为**独立感应面板**（368×290 取景区 + 四角标定框 + 扫描线 + 状态徽章），可收起
- 右栏整体可滚动，矮窗口下画布不会被挤没；窗口 < 1180px 自动回落单栏
- 画布支持「放大」成 940px 大面板（ESC 或点遮罩还原）

### 修复与改进

- 「清空全部数据」此前**不清 AI 记忆**——记忆是最私密的一类数据，这个口子不能留。现已一并清空，文案同步写明。
- 底噪标定被 0 短路：原先用 `noiseFloor < 0` 兼作"是否还在采样"的状态标记，安静环境下首个采样窗口为 0，赋值后再也进不去标定分支，自适应永久失效。改用独立布尔 `_calibrated`。
- 环图布局会退化：流程图中若全是环（无入度为 0 的节点），Kahn 分层会连锁把 3 个节点推成 5 层。改为整环铺在同一层，连线走虚线回边样式。
