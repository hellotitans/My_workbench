# 版本记录

## V0.1（2026-09-19）

把「记生活」升级成「能聊、能记、能看见」。AI 接入 + 工具调用 + 记忆 + 声场球 + 画布空间，五个里程碑一次成型。

### 本次新增

- **AI 接入（M1）**：OpenAI 兼容协议，Base URL / 模型名 / API Key 三件套通吃各家；多配置可存可切。密钥只存本机 localStorage，**不进导出的备份文件**（导出前有正则守卫兜底）。已实测 CORS：DeepSeek / 百炼 / 火山 / 智谱 / Moonshot / 硅基流动全部允许浏览器直连 → 纯前端直连，不需要后端代理。
- **AI 对话（M2）**：SSE 流式，逐字上屏；对话框形态（我在右、AI 在左，带头像与时间）。流式失败自动回退非流式再试一次。
- **工具调用（M3）**：AI 能真的改你的数据，但有三道保险——① 写操作先出**预览卡**（写明"从什么改成什么"）等人点确认；② 执行前全量快照入撤销栈（最近 5 次，可一键撤销）；③ 工具名归一化 + 参数校验。
- **记忆层（M4）**：`save_memory` 三道闸门——结构化 schema（缺字段整批拒收）、来源分级（`stated` 用户说的 / `inferred` 你推断的，**无 evidence 一律拒收**）、敏感黑名单（健康/财务/位置/密钥命中即拒，连确认卡都不弹）。冲突检测**并列保存不覆盖**。打分取 top-12 注入系统提示。
- **声场球（M5）**：从 3D_soundfield 移植的 Canvas 2D 手写 3D 投影球，零依赖。四态 `idle / listening / thinking / speaking`，三个维度同时区分（点阵层内外、光晕内收外扩、色相旋转）。语音活动检测：自适应底噪 1.2s + 双门限滞回 + hangover 500ms + 300~3000Hz 人声加权。麦克风只在点击时申请，**离开板块必收摊**（停 rAF + 停音轨 + 关 AudioContext）。
- **画布空间（M7）**：AI 通过 `render_canvas` 工具把结构化内容落到右侧画布——`explain` 结构化解释、`plan` 目标拆解、`flow` 流程/逻辑关系图（SVG 自动分层布局）。画布渲染不打断对话；`plan` 的「落到今日清单 / 存成长期目标」才走写操作确认卡。

### 界面调整

- 对话板块改为**左右双栏**：左对话，右「声场感应 + 画布空间 + 预留位」
- 声场球从 152px 条状升级为**独立感应面板**（368×290 取景区 + 四角标定框 + 扫描线 + 状态徽章），可收起
- 右栏整体可滚动，矮窗口下画布不会被挤没；窗口 < 1180px 自动回落单栏
- 画布支持「放大」成 940px 大面板（ESC 或点遮罩还原）

### 修复与改进

- 「清空全部数据」此前**不清 AI 记忆**——记忆是最私密的一类数据，这个口子不能留。现已一并清空，文案同步写明。
- 底噪标定被 0 短路：原先用 `noiseFloor < 0` 兼作"是否还在采样"的状态标记，安静环境下首个采样窗口为 0，赋值后再也进不去标定分支，自适应永久失效。改用独立布尔 `_calibrated`。
- 环图布局会退化：流程图中若全是环（无入度为 0 的节点），Kahn 分层会连锁把 3 个节点推成 5 层。改为整环铺在同一层，连线走虚线回边样式。

## V0.0（2026-09-18）

首个对外基线版本。七大板块 + 设置全部可用，源码、启动方式、需求与技术文档一并归档。

### 本次基线包含

- **首页总览**：日期卡与陪伴天数、「今天要处理」（逾期标红+顺延来源）、7 板块打卡墙（当日印章）、快速备忘、**本周打卡概览**（7 板块 × 最近 7 天圆点矩阵）
- **今日计划**：长期 → 短期 → 今日清单三级链路，未完成自动顺延，轻提醒卡片
- **学习进度**：章节进度 + 五种关系类型的知识树记录（可无限层级）
- **开发工作**：项目与任务管理（任务区可折叠）、Bug/灵感/版本随手记、**点击项目联动过滤右侧记录**
- **生活记录**：饮食（近 14 天）、健身、娱乐、身体管理与体重趋势 SVG 折线
- **今日心得**：今日主题（一句话点题 + 圆角矩形关键词）、富文本正文、心法与行动提炼、心法库检索
- **建设打卡**：习惯网格、每日正反馈、Make a difference、神经回路自塑、习惯 Build、30 天热力图、04:00 日切与 7 天补打卡、双击就地编辑
- **数据与设置**：JSON 导出/导入（含全部建设打卡字段）、主题切换、示例数据清理、累计 30 条备份提示

### 修复与改进（V0.0 归档时）

- 补齐 `exportJSON()` 缺失的 `buildBuilds` 字段（此前导出会丢失「习惯 Build」记录）
- 存储层增加可写性探测与内存降级，云端 iframe / 隐私模式下不再卡死
- 首页「建设打卡」此前落在 `locked` 兜底分支显示"建设中 V2"，现已接入真实打卡判定并纳入本周概览
