## 1. 技术选型与硬约束

| 项 | 选择 | 原因 |
|---|---|---|

## 3. 总体架构

### 3.1 分层

```
数据层   store.get / store.set / saveAll()   —— 只负责读写 localStorage
计算层   planCheckin / lifeCheckin / ...     —— 只做判定与聚合，不碰 DOM
渲染层   renderHome / renderPlan / ...       —— 只读数据更新 DOM，不互相调用
调度层   go(key) / refreshXxx()              —— 唯一入口，按序触发各渲染函数
```

### 3.2 单向调用（防循环递归）

**渲染函数之间严禁互调**。所有联动走统一入口：

```js
function go(key){          // 路由：切页时调用对应 renderXxx()
  currentKey = key;
  if(key === "home")  renderHome();
  if(key === "plan")  renderPlan();
  ...
}
```

用户交互的标准链路：
```
事件回调 → 改数据 → store.set / saveAll() → renderXxx()  // 单一渲染入口，不串联
```

> 历史教训：早期版本出现过「日历渲染」与「当天列表渲染」互相调用导致栈溢出。语法检查拦不住，只能靠架构约束。

### 3.3 模块注册

```js
var MODULES = [
  { key: "home",  name: "首页总览", icon: "home",  ... },
  { key: "plan",  name: "今日计划", icon: "plan",  ... },
  { key: "study", name: "学习进度", ... },
  { key: "dev",   name: "开发工作", ... },
  { key: "life",  name: "生活记录", ... },
  { key: "note",  name: "今日心得", ... },
  { key: "build", name: "建设打卡", ... },
  { key: "set",   name: "数据与设置", hide: true, ... }
];
```
侧边栏、首页打卡墙、本周概览均由此表驱动，新增模块只需加一条。

## 4. 存储层

```js
var PREFIX = "wb_life_";
var _memStore = {};        // localStorage 不可写时的内存兜底
var _storageFallback = false;

// 启动时探测一次可写性
(function(){ try{ localStorage.setItem(PREFIX+"__probe__","1"); localStorage.removeItem(...); }
             catch(e){ _storageFallback = true; } })();
```

- `store.get(k, def)` / `store.set(k, v)` / `store.del(k)` 全量 try/catch
- 写入失败 → 自动切内存存储，页面照常可用，`init()` 后 toast 提示"数据仅本次有效，请及时导出备份"
- **用途**：云端 iframe 托管或隐私模式下 localStorage 被禁用时不白屏

## 6. 关键实现

### 6.1 日切规则

- 全局：`todayStr()` 按自然日（00:00 分界）
- 建设打卡：`bdToday()` 按 **04:00 分界**（`new Date(Date.now() - 4*3600000)`），熬夜打卡算前一天
- 补打卡窗口：`bdCanEdit(date)`，7 天内可改，更早只读

### 6.2 顺延逻辑 `carryover()`

```
每次进入计划页 / 导入后执行：
1. 保险栓：内存中长期/短期数据为空时，从 store 反向恢复
2. 遍历 todays：未完成且 date < today → date = today，originalDate 保留首次日期
3. 写入 saveAll()
```
列表中对有 `originalDate` 的未完成项显示红色"逾期 · 顺延自 X 月 X 日"。

### 6.3 打卡判定

各模块一个 `xxxCheckin()`，返回 `{state, ...}`，`state` 取值 `done` / `undone` / `none`：

| 模块 | 判定 |
|---|---|
| 今日打卡（备忘） | 当天有备忘记录 |
| 今日计划 | 当天清单全部完成 |
| 学习进度 | 当天有学习记录，或章节 `doneAt` 为今天 |
| 开发工作 | 当天新增随手记 / 任务完成 / Bug 修复，任一 |
| 生活记录 | 当天健身、饮食、娱乐、身体任一有记录 |
| 今日心得 | 当天有关键词 / 一句话 / 正文 / 心法 / 行动任一 |
| 建设打卡 | 当天有打卡次数或备注，或三条记录任一 |

### 6.4 首页印章与本周概览

- `STAMP_CHARS = {home:"记", plan:"计", study:"学", dev:"作", life:"活", note:"悟", build:"建"}`
- 印章仅在 `state === "done"` 时渲染，CSS 为红框双线 + 8° 旋转 + 楷体
- `wkModuleHas(key, date)`：按日期复算各模块是否有记录（与印章判定同源）
- `renderWeekOverview()`：最近 7 天用 `shiftDateStr(-i)` 生成，今日列加 `.today`（虚线外圈）

### 6.5 开发页项目联动

```js
var devCur  = null;   // 选中项目 id，右侧随手记按 projectId 过滤
var devOpen = {};     // 折叠集合，{id: true} 表示已折叠（默认展开）
```
- 折叠键 `.pj-toggle` 只控制任务区显示（task-list + add-task-row 整块）
- 点击项目名 → `devCur` 切换；右侧列表、统计、录入下拉三者同步；顶部出现提示条
- 删除项目时清理 `devCur` / `devOpen`

### 6.6 富文本（心得正文）

`contenteditable` + `document.execCommand`，工具栏自选：bold / italic / fontSize / foreColor / hilite / 有序无序列表 / removeFormat。内容以 HTML 字符串存进 `insightMap[date].body`，读取时按原文回灌。

### 6.7 导出 / 导入

- 导出：构造对象 → `Blob` → `a.download`，文件名 `我的生活台备份_YYYY-MM-DD.json`
- 导入：`FileReader` → `JSON.parse` → 逐字段兜底 → 二次确认覆盖 → `saveAll()` → `carryover()` → 重新渲染
- 导出字段完整性已核对（含 `buildBuilds`）

### 6.8 示例数据

首次打开（localStorage 为空）时 `seedDemo()` 写入：
- 长期/短期/今日清单（含 1 条逾期）
- 学习项目 + 章节、开发项目 + 任务 + 三条随手记
- 饮食/健身/娱乐/体重序列（体重带 14 天种子数据）
- 两天心得示例（含关键词、心法、行动）
设置页提供「清空示例数据」。

## 8. 部署与发布

### 8.1 在线页面（资料库托管）

页面作为 HTML 产物上传到 WorkBuddy 资料库，得到协作态访问链接：
`https://www.workbuddy.cn/space/d/<nodeId>`，登录账号即可打开，可存书签 / 手机添加到主屏幕。

更新流程：本地改完 HTML → 用资料库导入能力重传同一节点（链接不变）。

### 8.2 本地启动包

`我的生活台启动包/Start.bat`：优先打开工作区主文件（永远最新），找不到则退回同目录副本。
内容为**纯 ASCII**（Windows batch 处理中文文件名易乱码，用 `for %%f in ("%~dp0*.html")` 动态取文件名规避）。
可把快捷方式放进 `shell:startup` 实现开机自启。

### 8.3 数据同步策略

> **本地打开 与 在线链接 是两套互不相通的 localStorage 数据**（不同源）。

跨端搬运：A 处「导出 JSON」→ B 处「导入恢复」。建议固定一个主用入口，另一个作为查看/备份。

## 9. 测试与验证

采用 **CDP（Chrome DevTools Protocol）驱动无头 Edge** 做端到端冒烟，脚本位于 `.workbuddy/`（不入库）：

| 脚本 | 覆盖 |
|---|---|
| `test-smoke.js` | 页面加载、模块数与页数、存储读写 round-trip、无初始化错误 |
| `test-home.js` | 首页印章数量与字形、本周概览行列数、今日列高亮、主题切换 |
| `test-dev.js` | 项目折叠、右侧列表联动过滤、空态文案、组合状态 |
| `test-note.js` | 今日主题合并卡、关键词圆角矩形（计算样式断言）、添加/删除 |

**踩坑记录**：
- 无头 Edge 用命令行加载 `file://` 会走缓存导致"代码没生效"假象，必须用 `Page.navigate` 强制重载
- 无头进程会随 shell 调用结束被回收，启动浏览器与执行测试必须在同一次调用内完成
- Node 22 内置的是 WHATWG `WebSocket`（`addEventListener`），不是 `ws` 包的 `on()` API

## 10. 已知约束

| 约束 | 说明 |
|---|---|
| 多设备不同步 | 当前为手动导 JSON；实时同步需引入云端数据表 |
| 清缓存会丢数据 | localStorage 被清理后无法恢复，务必定期导出 |
| 单文件体积 | 约 230KB，仍在舒适区；继续膨胀可考虑拆分构建 |
| 富文本依赖 execCommand | 该 API 已标记废弃但所有主流浏览器仍支持，短期无风险 |
| 在线页为协作态 | 未公开发布，需登录访问；发布为公开链接后任何拿到链接的人都能打开页面（数据仍在各自浏览器本地） |
