# 我的生活台 · 需求文档

> 版本：V0.0（2026-09-18 基线）
> 形态：单文件 HTML 个人工作台，数据存本机浏览器

---

## 1. 产品定位

一个**给自己用的个人工作台**：把每天散落的计划、学习、开发、生活、复盘，收进同一个页面里，让"今天做得怎么样"在一屏内看得见。

设计上的三条底线：

1. **打开就看见**：首页置顶「今天要处理」，不靠推送、不靠提醒，打开即见。
2. **只记提炼，不记流水账**：今日心得强制一句话点题 + 关键词；正文鼓励写"学到了什么"，而不是"做了什么"。
3. **数据归自己**：全部数据存在本机浏览器，不上传服务器；可随时导出 JSON 带走。

---

## 2. 使用节奏（典型一天）

| 时段 | 动作 |
|---|---|
| 早上 | 打开首页看「今天要处理」和昨天的顺延项；在「今日计划」补一条清单 |
| 白天 | 随手记：备忘、开发随手记（Bug/灵感/版本）、学习记录 |
| 晚上 | 「建设打卡」勾习惯、写每日正反馈；「今日心得」写一句话点题 + 关键词 + 心法 |
| 周末 | 「心法库」回看本周沉淀；顺手导出一次 JSON 备份 |

---

## 3. 设计原则

**语气**：积极直白、催行动，不文艺抒情。例："别想了，先动手做 5 分钟。""别等状态好了再做，做了状态才会好。"

**视觉**：
- 卡片圆角、留白充足，一屏不超过 4~6 个信息块
- 图标全部内联 SVG，**不使用 emoji 当图标**
- 深色 / 浅色双主题，跟随系统偏好可手动切
- 强调色克制使用：完成=绿、待办=橙、问题=红、主题=蓝

**交互**：
- 每个操作都要有即时反馈（toast / 状态变化）
- 破坏性操作（删除、清空、导入覆盖）必须二次确认
- 未完成的事不消失：今日清单未完成次日自动顺延并标红

## 4. 模块需求

### 4.1 首页总览

| 项 | 内容 |
|---|---|
| 目标 | 一屏看清"今天要干什么 / 干了什么" |
| 日期卡 | 当日日期与星期、每日轮换的行动型问候语、"已陪伴你 N 天" |
| 今天要处理 | 汇总今日清单未完成项；逾期项标红并注明顺延自哪天；一键勾选完成 |
| 今日打卡 | 7 个板块的当日状态卡：图标+名称在左、状态小字在右（弱化）；**当天有记录即盖朱红印章**（记/计/学/作/活/悟/建） |
| 快速备忘 | 想到什么记什么，Ctrl+Enter 保存，不分类 |
| 本周打卡概览 | 行=7 个板块，列=最近 7 天；实心点=当天有记录，今日列带虚线外圈高亮 |

**验收点**：任何板块当天有有效动作，首页对应卡片必须出现印章，概览对应格子必须是实心点。

---

### 4.2 今日计划

| 项 | 内容 |
|---|---|
| 目标 | 把"大目标"拆到"今天能做的一件事" |
| 长期计划 | 目标 + 说明 + 截止日 |
| 短期计划 | 从长期目标拆出，可一键加入今日清单 |
| 今日清单 | 当天要做的事；勾选完成 |
| 顺延规则 | 未完成项次日自动滚到今天，`originalDate` 保留原始日期，列表标红显示"逾期 · 顺延自 X 月 X 日" |
| 轻提醒 | 米黄卡片，根据当前数据智能生成一句提醒，可"换一句" |

**验收点**：昨天没做完的条目，今天打开必须还在，且带有逾期标记。

---

### 4.3 学习进度

| 项 | 内容 |
|---|---|
| 目标 | 追课程 / 书籍的章节进度，沉淀可回看的知识树 |
| 章节进度 | 学习项目 → 章节勾选，显示百分比进度条 |
| 知识树记录 | 每日学习记录，支持五种关系类型：为什么 / 所以呢 / 反过来 / 像什么 / 怎么用 |
| 掌握度 | 每条记录可标"学习中 / 已掌握" |
| 树状结构 | 记录可无限层级展开（父子节点），支持折叠 |

---

### 4.4 开发工作

| 项 | 内容 |
|---|---|
| 目标 | 项目、任务、随手记三者联动 |
| 项目管理 | 项目名 + 说明 + 状态（进行中/暂停/已完成），任务完成百分比进度条 |
| 任务区折叠 | 每个项目名左侧有展开/折叠键，收起时隐藏任务列表与添加行 |
| 随手记 | 三类：Bug（可标记解决）、灵感、版本里程碑 |
| 项目联动 | **点击项目名 → 右侧随手记只显示该项目关联的记录**，顶部出现"只显示「X」的记录 + 取消"提示条，统计随之收窄，录入表单自动选中该项目 |
| 打卡判定 | 当天有新增记录 / 任务完成 / Bug 修复任一动作即打卡 |

---

### 4.5 生活记录

| 项 | 内容 |
|---|---|
| 目标 | 记身体和日常，不做严肃的健康管理 |
| 饮食 | 早/中/晚/加餐，按天保存，自动保留最近 14 天 |
| 健身 | 自由记录条目，按天累计 |
| 娱乐 | 游戏 / 娱乐记录 |
| 身体管理 | 睡前时间、入睡时间、状态、体重；设置身高与目标体重后，自动算 BMI 与达成进度 |
| 体重趋势 | 内联 SVG 手绘折线图，窗口变化时重绘 |

---

### 4.6 今日心得

| 项 | 内容 |
|---|---|
| 目标 | 把一天压缩成能回看的几句话 |
| 今日主题 | 一句话点题（上）+ 关键词（下，回车添加，≤5 个）；关键词以**圆角矩形**展示（非胶囊） |
| 心得正文 | 富文本：加粗、斜体、字号、颜色、高亮、有序/无序列表、清除格式 |
| 心法提炼 | 可迁移的思路视角，自动沉淀进心法库 |
| 行动提炼 | 能落地的步骤，可一键加入今日计划 |
| 心法库 | 按日期回看所有心得，支持关键词筛选；显示来源日期与关键词 |

---

### 4.7 建设打卡

| 项 | 内容 |
|---|---|
| 目标 | 用"建设"而不是"坚持"的视角做习惯 |
| 习惯打卡 | 4 列卡片网格，可增减自定义习惯项；每项记次数与备注 |
| 每日正反馈 | 今天做到的一件小事 |
| Make a difference | 今天做的一件有影响力的事 |
| 神经回路自塑 | 单行输入 + 添加按钮 |
| 习惯 Build | 关联到某条"神经回路自塑"记录（类似"短期关联长期"） |
| 热力图 | 左列竖向项目名 + 最近 30 天方块矩阵，同排起点对齐 |
| 补打卡窗口 | 04:00 为一天分界；7 天内可补打，更早仅可查看 |
| 快捷编辑 | 双击列表文字就地编辑，Enter 保存 / Esc 取消 |

---

### 4.8 数据与设置

| 项 | 内容 |
|---|---|
| 导出备份 | 一键导出全部数据为 JSON（文件名带日期） |
| 导入恢复 | 选择 JSON 恢复，覆盖前二次确认；兼容旧版本缺字段 |
| 清空数据 | 二次确认 |
| 主题 | 深色 / 浅色切换，记忆偏好 |
| 统计 | 各板块数据条数 |
| 备份提示 | 数据累计 ≥30 条时，首页顶部温和提示导出 |

## 5. 非功能性需求

| 类别 | 要求 |
|---|---|
| 体积与依赖 | 单文件 HTML，零外部依赖（无 CDN、无字体外链、无图表库），离线可用 |
| 性能 | 4200+ 行单文件，本地秒开；渲染按模块独立触发 |
| 隐私 | 数据不出本机；部署的在线页面不预填任何真实私密数据 |
| 移动适配 | <860px 单列堆叠；输入框字号 ≥16px 防 iOS 缩放 |
| 数据安全 | 导出/导入闭环；存储不可写时自动降级为内存模式并提示导出 |
| 向后兼容 | 新增字段不破坏旧数据；导入时逐字段兜底 |
