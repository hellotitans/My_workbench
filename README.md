# 我的生活台 · My Workbench

一个**单文件、零依赖、数据存本机**的个人工作台。把每天的计划、学习、开发、生活记录和复盘收进同一个页面，让"今天做得怎么样"一屏看得见。

```
personal-workbench.html   ← 就这一个文件，双击即用
```

---

## 快速开始

**方式一：直接用**
双击 `personal-workbench.html`，或用浏览器打开它。数据保存在当前浏览器里，关掉再开还在。

**方式二：启动包（推荐日常用）**
进 `我的生活台启动包/`，双击 `Start.bat`。想让它开机自启：右键 `Start.bat` → 创建快捷方式 → `Win+R` 输入 `shell:startup` → 把快捷方式拖进去。

**方式三：在线访问**
工作台已托管到 WorkBuddy 资料库，登录账号打开链接即可，手机浏览器打开后「添加到主屏幕」可以当 App 用。

## 七个板块

| 板块 | 解决什么 |
|---|---|
| **首页总览** | 一屏看清今天：要处理的事、7 个板块打卡状态（当天有记录会盖印章）、最近 7 天打卡概览 |
| **今日计划** | 长期目标 → 短期拆分 → 今日清单；没做完的次日自动顺延并标红 |
| **学习进度** | 课程/书籍章节进度 + 知识树记录（为什么/所以呢/反过来/像什么/怎么用） |
| **开发工作** | 项目与任务（任务区可折叠）、Bug/灵感/版本随手记，点项目即联动过滤 |
| **生活记录** | 饮食、健身、娱乐、身体管理与体重趋势 |
| **今日心得** | 一句话点题 + 关键词，富文本正文，心法与行动提炼，心法库回看 |
| **建设打卡** | 习惯网格、每日正反馈、Make a difference、神经回路自塑、30 天热力图 |

外加「数据与设置」：JSON 导出/导入、主题切换、示例数据清理。

---

## 关于数据（重要）

- 数据存在**你自己浏览器的 localStorage**，不上传服务器，别人打不开你的记录。
- **本地打开 和 在线链接 是两套互不相通的数据**。跨端搬运：一处「导出 JSON」→ 另一处「导入恢复」。
- 每周导出一次 JSON 存好；**不要清浏览器网站数据**，清了本地记录就没了。

## 技术要点

- 单个 HTML 文件（约 230KB，4300 行），CSS/JS/图标全部内联
- **零外部依赖**：不引任何 CDN、框架、字体、图表库；图表与图标均为手写 SVG
- 深色 / 浅色双主题，<860px 自动单列，手机可用
- 渲染函数单向调用、统一刷新入口，杜绝递归渲染
- 存储不可写时（隐私模式等）自动降级为内存模式并提示导出

详见 [技术文档](docs/02-技术文档.md)。
