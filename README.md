# 我的生活台 · My Workbench

一个**单文件、零依赖、数据存本机**的个人工作台。

V0.0 让它能**记**：计划、学习、开发、生活、复盘收进同一个页面，"今天做得怎么样"一屏看得见。
V0.1 让它能**聊、能记、能看见**：接得上大模型，AI 能真的改你的数据（但你说了算），
你说过的重要的事它记得住，说话时有一个跟着声音起伏的声场球，需要展开讲的内容会落到右侧画布上。

```
personal-workbench.html   ← 就这一个文件，双击即用
```

---

## 快速开始

**方式一：直接用**
双击 `personal-workbench.html`，或用浏览器打开它。数据保存在当前浏览器里，关掉再开还在。

**方式二：启动包（推荐日常用）**
进 `我的生活台启动包/`，双击 `Start.bat`。想让它开机自启：右键 `Start.bat` → 创建快捷方式 → `Win+R` 输入 `shell:startup` → 把快捷方式拖进去。

**方式三：在线访问**
工作台已托管到 WorkBuddy 资料库，登录账号打开链接即可，手机浏览器打开后「添加到主屏幕」可以当 App 用。

## 九个板块

| 板块 | 解决什么 |
|---|---|
| **首页总览** | 一屏看清今天：要处理的事、7 个板块打卡状态（当天有记录会盖印章）、最近 7 天打卡概览 |
| **今日计划** | 长期目标 → 短期拆分 → 今日清单；没做完的次日自动顺延并标红 |
| **学习进度** | 课程/书籍章节进度 + 知识树记录（为什么/所以呢/反过来/像什么/怎么用） |
| **开发工作** | 项目与任务（任务区可折叠）、Bug/灵感/版本随手记，点项目即联动过滤 |
| **生活记录** | 饮食、健身、娱乐、身体管理与体重趋势 |
| **今日心得** | 一句话点题 + 关键词，富文本正文，心法与行动提炼，心法库回看 |
| **建设打卡** | 习惯网格、每日正反馈、Make a difference、神经回路自塑、30 天热力图 |
| **AI 对话** ⭐ | 流式对话；AI 能读写你的数据，但写操作**先出预览卡等人点头**，可一键撤销；右侧是声场感应面板与画布空间 |
| **数据与设置** | 模型配置、AI 记忆、JSON 导出/导入、主题切换、示例数据清理 |

## V0.1 的五个能力

**① AI 接入（协议而非某一家）**
Base URL / 模型名 / API Key 三件套，走 OpenAI 兼容协议，换服务商不改代码。
实测 DeepSeek / 百炼 / 火山 / 智谱 / Moonshot / 硅基流动均允许浏览器直连 —— **纯前端就能连，不需要后端代理**。
密钥只存本机 localStorage，**不进导出的备份文件**（导出前有正则守卫兜底）。

**② 工具调用（AI 能改数据，但你说了算）**
三道保险：写操作先弹**预览卡**（写明"从什么改成什么"）→ 确认后执行前**全量快照入撤销栈**（最近 5 次，一键回滚）→ 工具名归一化 + 参数校验。
读操作直接执行，不打断对话。

**③ 记忆层（关键不是"让模型别瞎编"，而是"瞎编的进不了库"）**
三道闸门：结构化 schema（缺字段整批拒收）→ 来源分级（用户说的 `stated` / 模型推断的 `inferred`，**无依据一律拒收**）→ 敏感黑名单（健康/财务/位置/密钥命中即拒，连确认卡都不弹）。
冲突时**并列保存不覆盖**，交给人判断。按置顶 / 命中次数 / 时间衰减打分取 top-12 注入系统提示。

**④ 声场球（Canvas 2D 手写 3D 投影，零依赖）**
从音频可视化项目移植的数学与渲染核心，去掉 HUD 与调试面板，压进工作台的四态状态机：
`idle` / `listening` / `thinking` / `speaking` —— 四个态在**三个维度上同时区分**（点阵层内外、光晕内收 vs 外扩、色相旋转），只差一层的话两个态会长得几乎一样。
语音活动检测：自适应底噪 1.2s + 双门限滞回 + hangover 500ms + 300~3000Hz 人声加权。
**麦克风只在点击时申请，离开板块必收摊**（停 rAF + 停音轨 + 关 AudioContext），页面切后台暂停。

**⑤ 画布空间（AI 把结构化内容落到面板上）**
AI 通过 `render_canvas` 工具产出结构化 JSON，前端渲染成三类内容：

| 类型 | 场景 | 长什么样 |
|---|---|---|
| `explain` | 答疑 / 科普 | 分层卡片：一句话结论 → 要点 → 类比/例子 → 常见误解 |
| `plan` | 目标拆解 | 目标 → 阶段 → 步骤的阶梯，可一键落到今日清单 / 长期目标 |
| `flow` | 技术 / 逻辑关系 | SVG 流程图，**模型只给节点和边，坐标由前端拓扑分层算** |

画布渲染**不打断对话**；只有 `plan` 真正落库时才走写操作确认卡。参数不合法则静默降级为普通文字回答。

## V0.2（进行中）· 语音输入

说话就能输入：点开麦克风，说完一句停顿一下，声音被转成文字**填进输入框等你确认**——
不自动发送，你可以改完再发。

- **云端优先 + 原生兜底**：配了密钥走云端识别；没配或调用失败，自动切浏览器自带识别
- **连续听、自动断句**：不用一直按着，接着说下一句会继续往输入框里追加
- **复用同一条麦克风流**：与声场球共用一份音频，不二次申请权限；关麦 / 离开板块 / 切后台一律收摊
- 实测十家接口，只有硅基流动的语音接口同时满足「浏览器可直连」+「通用协议格式」，
  设置页已默认填好地址与模型名，你只补一个密钥

## 关于数据（重要）

- 数据存在**你自己浏览器的 localStorage**，不上传服务器，别人打不开你的记录。
- **本地打开 和 在线链接 是两套互不相通的数据**。跨端搬运：一处「导出 JSON」→ 另一处「导入恢复」。
- 每周导出一次 JSON 存好；**不要清浏览器网站数据**，清了本地记录就没了。

## 技术要点

- 单个 HTML 文件（约 358KB，7081 行），CSS/JS/图标全部内联
- **零外部依赖**：不引任何 CDN、框架、字体、图表库；3D 球、流程图、图表与图标均为手写 SVG / Canvas
- 深色 / 浅色双主题，配色读 CSS 变量，声场球跟随主题换肤
- 渲染函数单向调用（DAG）、统一刷新入口，杜绝递归渲染；模块注册表驱动侧边栏与首页打卡墙
- 对话页双栏：左对话 / 右感应与画布，<1180px 自动回落单栏
- 存储不可写时（隐私模式等）自动降级为内存模式并提示导出
